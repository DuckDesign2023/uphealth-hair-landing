# План: качественные визуалы с реальной этикеткой

31.07.2026, v2. Заменяет прошлый план целиком.

## Факты, от которых считаем

1. **Реальная съёмка продукта уже в репозитории**: `_labels/orig/duo-packshot.png`,
   `serum-packshot.png`, `botanical-packshot.png` — это фото из карточек Supliful
   (подтверждено скрином карточки от клиента: тот же кадр). Этикетка на них настоящая:
   шалфейная плашка, «uphealth», объём.
2. Наложение плоской этикетки на фото (вчерашний подход) забраковано клиентом — выглядит
   наклейкой. Больше не используется; композиты вычищаются.
3. Женская линейка — зелёная этикетка, мужская — красная `#885049` (правило клиента).
4. Генерация с нуля переписывает текст этикетки. Поэтому для мужской версии — не новая
   съёмка, а **редактирование реального фото** (nano banana: поменять цвет плашки,
   текст не трогать). Текста на этикетке два слова — риск минимальный.

## Шаги

### 1. Женская версия — только готовые материалы, ноль генерации
- Восстановить из `_labels/orig/` затёртые композитами файлы: `duo-packshot`,
  `serum-packshot`, `botanical-packshot`.
- Карточки товара и панели серумов (`pack-peptide`, `pack-botanical`, `pack-duo`)
  перевести на реальные фото: amber 30 ml → pack-peptide, frosted 59 ml → pack-botanical,
  дуо → pack-duo. Название продукта и так написано текстом в карточке — фото с
  «uphealth + объём» ровно как у настоящего товара.
- `hero-bunch-cutout` не трогаем: на нём этикетка уже читается как «uphealth» — совпадает
  с реальной. Женский лайфстайл (`life-*`) — тоже: этикетки там шалфейные «uphealth».

### 2. Мужская версия — те же фото, этикетка в кирпичный
- Три исходника (amber, frosted, duo) прогнать через nano banana pro: «этикетка
  #885049, текст кремовый, всё остальное не менять».
- Проверить текст после генерации (uphealth / 30 ml / 59 ml — без искажений).
- Разложить: duo → `men/assets/duo-packshot.png` (hero) и `pack-duo.png`;
  amber → `pack-peptide.png` и `serum-packshot.png`; frosted → `pack-botanical.png`
  и `botanical-packshot.png`.

### 3. Мужской лайфстайл с браком на этикетке
- `life-m6` (и проверить m3/m4): нечитаемая «каша» на флаконе → тем же редактированием
  заменить этикетку на кирпичную «uphealth». Кадры без читаемой этикетки не трогаем.

### 4. Сдача
- Все генерации (включая брак) → `_generated/men/`; отобранное → `_deliver/` плоским
  списком для передачи клиенту.
- Версии `?v=` поднять, прогнать обе страницы, опубликовать в main + gh-pages.
