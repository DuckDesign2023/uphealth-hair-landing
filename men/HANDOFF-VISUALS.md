## Жёсткие правила проекта

1. Женскую версию (всё вне `men/`) не менять. Общие ассеты в `assets/` — только читать.
2. **Сохранять ВСЕ сгенерированные кандидаты, включая брак**, в `_generated/men/`. Клиент выбирает сам.
   Ничего не удалять.
3. Спорные решения показывать **страницей вариантов**, а не выбирать за клиента.
   Уже есть: `men/generated.html` (контактный лист всех генераций) и `men/ba-variants.html` (выбор до/после).
   Новые кандидаты добавлять туда же.
4. Весь пользовательский текст и превью-страницы — **только на английском**.
5. Стиль: флэт, без теней, hairline-бордеры 1px, иконки lucide 1px.
6. При правке `men/styles.css` или `men/index.html` — инкрементить `?v=N` в ссылке на CSS
   (сейчас `styles.css?v=9`, скрипт `../script.js?v=16`).
7. Публикация: `git add … && git commit && git push origin main`, затем
   `git checkout gh-pages && git merge main --ff-only && git push origin gh-pages && git checkout main`.
8. Анти-слоп: применять каталог `D:\MD-files\design-anti-slop` к результатам.

## ГЛАВНОЕ: калибровка фото «до/после»

История: сначала были сняты **студийные** диптихи (бесшовный фон, софтбокс, голова и плечи).
**Клиент их забраковал** — читается как реклама. Они сохранены в `_generated/men/r1-*, r2-*, r3-*`
и помечены на `men/generated.html` как superseded.

Правильное направление — **как реальные фото на hims.com/hair-loss**: это не съёмка, а снимки,
которые мужчины делали сами на телефон. Диван, ковёр, коридор, кухня, потолочный свет,
селфи на вытянутой руке, бытовой фон, лёгкий шум камеры.

**Требование клиента: разница должна быть НЕБОЛЬШОЙ. «Не показывай значительный рост волос».**

### Рабочий промпт-шаблон (soul_2, aspect 4:3)

```
Two amateur smartphone photos of THE SAME man side by side, separated by a thin white vertical gap
— a personal before-and-after taken at home. NOT a studio shoot. Same [room] in both frames
([детали обстановки]), same angle, same distance, same lighting. [Поза/ракурс.]

LEFT (before): [проблема — линия роста / макушка / диффузное поредение].

RIGHT (after): only a MODEST change — [чуть больше волос, чуть меньше просвечивает кожа].
[Проблема] is still clearly there. NOT a transformation, NOT noticeably thicker hair,
no new hairline.

Ordinary man about [возраст], [одежда и 2-3 несовершенства внешности].
[Бытовой свет], framing not quite level, mild phone-camera noise.
No studio backdrop, no seamless paper, no softbox, no professional lighting.
No film border, no slide frame, no sprocket holes, no caption strip, no text, no labels, no watermark.
```

### Что НЕ работает (проверено на 15 генерациях)

- **Висок в профиль / «temple corner»** — soul_2 стабильно рисует выбритую барберскую линию вместо
  поредения, даже с прямым запретом. Ракурс не использовать.
- **«hair on top is sparse» в описании before** — даёт «лысый → шевелюра», эффект парика.
  Описывать только углы линии роста + добавлять «still recognisably the same head of hair».
- **Плёночная рамка**: soul_2 регулярно рисует кадр «сканированным слайдом» — чёрные канты,
  перфорация, жёлтые надписи по краю. Запрет в промпте помогает не всегда, лечится кропом.
- **Читаемая этикетка на флаконе** — модель пишет выдуманный бренд («Slagioler», «NANNEER»,
  «SAALR MPTEE»). Поэтому: либо кадр без читаемой этикетки, либо настоящие пакшоты uphealth.
- Самый надёжный ракурс — **сверху при наклонённой вперёд голове**.

### Пайплайн обработки

- `_tools/split_ugc.py` — режет UGC-диптих на половинки: сам находит белый разделитель
  (он не по центру), срезает плёночную рамку, кропает в **квадрат от верха кадра**.
  Кроп от верха обязателен: при центральном `object-fit: cover` срезает макушку и линию роста.
- `_tools/trim_frames.py` — мягкий автокроп плёночных рамок.
- `_tools/split_ba_men.py` — то же для студийной партии (устарело).
- Готовые половинки кладутся в `men/assets/` как `cmp-<key>-before.jpg` / `cmp-<key>-after.jpg`.
