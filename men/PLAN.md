# uphealth for men — план секций (отличия от women-v1)

Структура и функциональность 1:1 с женской версией (тег `women-v1`). Меняются контент, лексика и визуалы.
Живёт в `men/`, женскую версию не трогаем. `script.js` переиспользуем из корня (`../script.js`), стили — свой `men/styles.css`.

## Сквозные правила мужской версии

| Женская | Мужская | Почему |
|---|---|---|
| ritual | **routine** | «ритуал» читается женственно; hims говорит «treatment / routine» |
| «Shop the ritual» | «Start the routine» | тот же слот CTA |
| «fuller, thicker hair» | «hairline / crown / density» | мужская боль называется по месту, а не по ощущению |
| эмоция, забота | факт, спокойная прямота | тон hims: без пафоса и без обещаний |
| зелёный эвкалипт + терракота | крем + эспрессо + кирпич | палитра с hims (см. `palette.html`) |

Новое, чего нет в женской (из референса hims, работает только на мужчинах):
**пилюли-теги проблемы** на карточках отзывов — `Receding hairline` / `Temple corners` / `Thinning crown`.

## Спорные решения → страницей вариантов на выбор

1. **Hero** — 3 заголовка × 2 композиции (сплит hims / центр как в женской).
2. **Секция «Where you're losing it»** — отдельный блок с line-art зонами (лоб / линия роста / макушка) ИЛИ то же самое, свёрнутое в hero-буллеты. Отдельный блок сильнее, но удлиняет страницу.
3. **Типографика** — T1 Hanken Grotesk (единство с женской) / T2 Figtree / T3 Instrument Sans. См. `palette.html`.

## Визуалы к генерации

- Пакшот hero: два флакона, жёсткий свет, без ботаники.
- Маркиза: 10 кадров с мужчинами (по калибровке портретов: студийно/чисто, обычные немодельные лица, одежда с реальной посадкой; без плёнки и винтажа).
- 6 диптихов до/после: **широкий план** (голова + плечи, воздух над головой), разница наглядная но без «копны» — рабочая формула промпта из памяти проекта.
- Line-art: нанесение на линию роста, схема зон потери (вид спереди + сверху).
- Эксперты, паки, печать, инфографика A/B — переиспользуем.
